# flow-prompts.md: imagens do jogo Exitus Kids (Colégio Christus)

Lista de todas as imagens que o jogo precisa, para gerar no **Google Flow (Nano Banana)**. O manifesto `exitus-kids/jogo/assets.js` já aponta para estes caminhos: salve cada imagem exatamente no arquivo indicado, dentro de `exitus-kids/jogo/`.

**Regras da série**
- Todo prompt repete o mesmo bloco de estilo e as mesmas descrições de personagem.
- Nenhum texto dentro das imagens. Letras, números, sílabas e títulos são desenhados pelo código por cima.
- Personagens, avatares e objetos ficam sobre fundo liso `#EAF4FF`, para recortar depois (exportar em PNG com transparência).
- Ordem sugerida: personagens → avatares → fundos → objetos → figurinhas. Em cada grupo, a primeira imagem vira a referência das seguintes.

Total: **55 imagens**.
